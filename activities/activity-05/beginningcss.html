QUESTIONS

1. Explain the difference between inline, embedded, and external CSS?

Inline CSS styles a single HTML element directly, embedded CSS styles one entire page from a 'style' block, and external CSS styles multiple pages from a separate '.css' file.

2. Explain why you should only use external CSS?

External CSS should be used because it keeps code clean, consistent, and easy to maintain across a website.

3. What is a selector used for?

A selector is used to target specific html elements so CSS styles can be applied to them.
